# Docside First Look

> **A private preview for selected real estate professionals.**

This repo holds the **guided preview & research experience** for [Docside](https://docside.ai) — personalized invite links at `preview.docside.ai/<invite-code>` that welcome an agent by name, place them in a realistic multi-offer listing scenario, walk them through four missions inside the real Docside app, and capture structured, candid feedback.

It is a research instrument, not a landing page. The question it exists to answer:

> **Can Docside explain itself, or does Morris have to explain it?**

## The Docside repo family

| Repo | Role |
|---|---|
| [`docside`](https://github.com/manderso90/docside) | The product — app, extraction pipeline, trust architecture |
| `docside-experience` | Experience definition — design system, trust doctrine, screen specs |
| `docside-first-look` (this repo) | The preview/research experience shell |
